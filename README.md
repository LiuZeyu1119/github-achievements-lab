# GitHub Achievements Lab

A small sandbox for practicing GitHub pull requests.

## Quickstart

1. Create a topic branch from the current default branch.
2. Make one focused change and inspect the diff.
3. Push the branch and open a pull request describing the change.
4. Merge the pull request and remove the finished topic branch.

## Merge checklist

- Confirm that the base and topic branches are correct.
- Keep the diff limited to the intended change.
- Validate the changed documentation or run the relevant tests.
- Confirm the merged state and delete the finished topic branch.
